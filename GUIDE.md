# CoT Bridge — инструкция (v0.3.2)

Мост между **LoRa-мешем Meshtastic** и **TAK-сервером** (заточен под URPC). Раздаёт
координаты и чат в обе стороны: то, что происходит в меше — уезжает на сервер и видно
друзьям в интернете; то, что на сервере — приезжает в меш и видно офлайн-нодам без
интернета. Ставится как обычное Android-приложение, отдельная железка не нужна.

Проверено вживую: друг на URPC → сервер → мост → LoRa → офлайн-нода видит его метку на
карте ATAK.

---

## 0. Как это устроено (за минуту)

```
        ┌──────────────── телефон-ШЛЮЗ (есть интернет) ─────────────────┐
        │  ATAK  ←→  CoT Bridge  ←→  Meshtastic (приложение) ←BT→ LoRa-нода
        │                  │
        └──────────────────┼────────── TLS (под cert'ом) ──────────────────┐
                           ▼                                                ▼
                    меш-ноды без интернета                            TAK-сервер URPC
                    (видят всё по LoRa)                          (друзья в интернете)
```

- **Шлюз** — один телефон, у которого есть и меш (через приложение Meshtastic + нода по
  BT), и интернет. На нём живёт мост.
- **Меш-ноды** — телефоны друзей в поле, только LoRa, без интернета. Видят серверные
  координаты, потому что мост вливает их в меш.
- **Анти-дубль:** в связном меше ретранслирует **ровно один** активный шлюз (выборы), —
  можно спокойно ставить мост нескольким людям, дублей на сервере не будет.

> **Важно про URPC:** URPC подменяет UID исходящих CoT на серверный (`SERVER-N`) по
> cert'у. Поэтому **у каждого свой сертификат** (Модель А) — «один cert на всех» ломает
> карту (одна иконка прыгает между людьми). См. `README_URPC.md`.

## 1. Что нужно поставить (на телефон-шлюз)

| Компонент | Зачем | Где взять |
|---|---|---|
| **Meshtastic Android** 2.7.13+ | связь с LoRa-нодой по BT | Google Play / [releases](https://github.com/meshtastic/Meshtastic-Android/releases) |

не нужен, они просто принимают по LoRa. Спаривание ноды и плагин — см. `INSTALL_GUIDE.md`.

## 2. Установка моста

1. Разреши установку из неизвестных источников, поставь APK.
2. При первом запуске выдай разрешения (уведомления, местоположение — нужно для работы
   сервиса).
3. **Обязательно** исключи «CoT Bridge» из энергосбережения: Настройки телефона →
   Батарея → CoT Bridge → **Без ограничений** (+ автозапуск на Xiaomi/Oppo/Samsung).
   Иначе OEM убьёт фоновый сервис и мост «уснёт».

## 3. Получить свой сертификат URPC

Мосту нужен клиентский cert от URPC, упакованный в **DataPackage (.zip)**.

### Вариант А — через ATAK (просто, рекомендуется)

1. В ATAK: **Settings → Network Preferences → TAK Servers → +**.
2. Хост `tak.urpc.info`, порт `8089`, включи **Enrollment**, введи свои **логин/пароль**
   от URPC. ATAK сам сходит на сервер и получит cert.
3. Экспортни это подключение как **Mission Package (.zip)**: в списке TAK-серверов открой
   меню сервера → **Export / Отправить как Data Package**. Получится `.zip` с `client.p12`
   + `truststore.p12` + `.pref`.
4. Пароль `.p12` по умолчанию — `atakatak`.

### Вариант Б — через enrollment API (продвинуто, без ATAK)

Сервер отдаёт cert по HTTP-enrollment. Кратко (нужен `openssl` + `curl`):

```bash
# 1. CSR
openssl req -new -newkey rsa:2048 -nodes -keyout client.key \
  -subj "/CN=ТВОЙ_EMAIL" -out client.csr
# 2. подписать на сервере (basic-auth логином/паролем URPC)
curl -u 'ЛОГИН:ПАРОЛЬ' --data-binary @client.csr \
  'https://tak.urpc.info:8446/Marti/api/tls/signClient/v2?clientUid=ТВОЙ_EMAIL&version=2.1'
# 3. забрать CA:  .../Marti/api/tls/config
# 4. собрать client.p12 (ключ+cert+цепочка) и .pref с connectString0=tak.urpc.info:8089:ssl,
#    заархивировать в .zip с паролем atakatak
```

Итог обоих вариантов — один `.zip`, который импортируем в мост.

## 4. Импорт cert в мост

1. В мосте: **Импорт DataPackage (.zip)** → выбери свой `.zip`.
2. **Пароль .p12** — `atakatak` (или свой, если менял).
3. **Callsign** — можно оставить пустым (возьмётся CN из cert'а) или задать позывной.
4. **Host/Port** — пусто (возьмётся из `.pref`).
5. Жми **Импорт**. В списке «Серты мешевых юзеров» появится запись.

> Один мост может держать несколько cert'ов (по одному TLS-коннекту на каждый) — но для
> обычного шлюза достаточно одного своего.

## 5. Настройка и старт

Прокрути к **«Режим шлюза (анти-дубль)»** и **«Обратка URPC → меш»**.

- **Роль шлюза:**
  - **AUTO** — по-умолчанию для всех, кому раздаёшь: в связном меше выбирается ровно один
    активный, есть failover. Безопасно.
  - **FORCE** — «всегда я, единственный, без failover». Ставь, если ты один шлюз.
  - **OFF** — не ретранслировать.
  - *Приоритет:* меньше = главнее; у самого мощного/стабильного шлюза ставь `0`.
- **Обратка URPC → меш:**
  - **RX (cert)** — рекомендуется: серверные CoT приходят напрямую из per-cert стрима.
    Надёжно.
  - **Multicast** — запасной, через ретрансляцию ATAK. На практике часто не работает —
    **используй RX**.

> ⚠️ Смена роли/режима применяется **только при следующем «Старте»**. В переключателях
> **серая** кнопка = выбранная, фиолетовая = «переключиться на».

Жми **Старт**. Должно стать:

- **Статус** — всё зелёное: Сервис запущен, Meshtastic AIDL OK, Шлюз — АКТИВНЫЙ.
- **Серты** — твой cert зелёный, `OK` (в логе `URPC [urpc]: connected`).

## 6. Проверка, что работает

**Счётчики** в мосте:

| Счётчик | Что значит |
|---|---|
| `меш → bridge` / `bridge → URPC` | меш → сервер (твои/чужие мешевые PLI уходят на URPC) |
| **`bridge → меш`** | **сервер → меш** (координаты с URPC вливаются в LoRa) — тикает, когда друг на сервере шлёт позицию |
| `Эхо-фильтр` | отфильтрованные эхо (свои же, вернувшиеся с сервера) |
| `Пропущено (не активный шлюз)` | этот мост сейчас в standby, ретранслирует другой |

**На дальней меш-ноде** (телефон друга без интернета): открой ATAK → **список контактов
(иконка людей)**. Позывной с сервера (напр. `Exe`) должен появиться с зелёным индикатором;
тап по нему — карта уезжает на его координаты. Значит путь сервер→меш замкнут.

---

## 7. Раздача друзьям

1. Каждому — **свой** cert (enrollment под его логином, п.3). Общий cert нельзя.
2. У всех роль **AUTO** (мост сам разберётся, кто активный). Если хочешь фиксированного
   главного — ему `priority=0`, остальным больше.
3. Обратка у всех — **RX (cert)**.
4. Всем — исключение из энергосбережения (п.2), иначе сервис умирает.

## 8. Если что-то не так

| Симптом | Причина / фикс |
|---|---|
| Cert вечно «соединяюсь», в логе `CertPathValidatorException: Trust anchor…` | Баг старых версий. **Обнови до v0.3.2+** — там trust-store собирается из цепочки cert'а. |
| Cert краснеет сразу | Неверный пароль `.p12` (обычно `atakatak`) или битый `.zip`. |
| `URPC connected`, но `bridge → меш` не растёт | Обратка стоит на **Multicast** — переключи на **RX (cert)** и нажми **Старт**. Либо на сервере сейчас никто не шлёт позицию. |
| Мост сам останавливается | OEM убил сервис — исключи из энергосбережения + автозапуск. |
| На карте одна иконка прыгает между людьми | Все сидят под одним cert'ом. Нужен **свой cert каждому** (URPC ремапит UID). |
| Меш→сервер идёт, обратка нет | Проверь, что этот мост — **АКТИВНЫЙ** шлюз (Статус), а не standby. |

Подробный траблшутинг ноды/BT/плагина — `TROUBLESHOOTING.md`.
